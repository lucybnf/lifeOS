# LifeOS

LifeOS es una aplicación web personal para organizar áreas importantes de la vida desde una interfaz simple, moderna y responsive.

## Estructura inicial

```text
/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── assets/
├── components/
├── pages/
└── README.md
```

- `index.html`: estructura base de la aplicación, menú principal, barra superior de búsqueda y botón de perfil.
- `css/styles.css`: estilos visuales, layout responsive, estados del menú, buscador y desplegable de perfil.
- `js/main.js`: interacción del menú, búsqueda/filtro de opciones, cambio de pantalla activa, perfil desplegable y apertura/cierre en móviles.
