# LifeOS

LifeOS es una aplicación web personal para organizar áreas importantes de la vida desde una interfaz simple, moderna y responsive.

## Estructura inicial

```text
/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── assets/
├── components/
├── pages/
└── README.md
```

- `index.html`: estructura base de la aplicación y menú principal.
- `css/styles.css`: estilos visuales, layout responsive y estados del menú.
- `js/main.js`: interacción del menú, cambio de pantalla activa y apertura/cierre en móviles.
